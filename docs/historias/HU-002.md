# HU-002: Cerrar sesión y proteger el acceso
**Épica:** E1 Acceso · **Prioridad:** alta · **Estimación:** 2 pts

**Como** QA usuario de Probo
**Quiero** cerrar mi sesión y que nadie sin sesión pueda ver mis datos
**Para** mantener privada mi información de pruebas

## Criterios de aceptación
- [ ] Dado un usuario con sesión iniciada, cuando hace clic en "Cerrar sesión", entonces vuelve al login y ya no puede ver pantallas internas con el botón "atrás" del navegador.
- [ ] Dado un visitante sin sesión, cuando entra directo a una URL interna (ej. `/historias`), entonces es redirigido al login.
- [ ] Dado un visitante sin sesión que fue redirigido al login, cuando inicia sesión, entonces vuelve a la URL que había pedido.

### API
- [ ] Todo endpoint bajo `/api` (excepto `/api/health` y `/api/auth/login`) sin token responde **401**.
- [ ] Con un token inválido, alterado o expirado responde **401**.

## Diseño relacionado
- 🎨 [Diseño UI (Probo UI)](https://claude.ai/artifact/Pe7F1K5x7XrggbH8wmc8fJ): botón **Cerrar sesión** en el header de todas las pantallas internas
- `docs/arquitectura/api.md` (autenticación)

## Notas
- **Decisión:** cerrar sesión borra el token del cliente; no hay lista negra de tokens en el servidor (MVP).
