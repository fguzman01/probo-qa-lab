# HU-003: Crear una historia de usuario
**Épica:** E2 Historias de usuario · **Prioridad:** alta · **Estimación:** 3 pts

**Como** QA
**Quiero** cargar una historia de usuario con sus criterios de aceptación
**Para** usarla como base para diseñar sus casos de prueba

## Criterios de aceptación
- [ ] Dado el formulario de nueva historia, cuando completa título, "Como", "Quiero", "Para" y al menos un criterio de aceptación, y guarda, entonces la historia se crea y ve su detalle.
- [ ] Dada una historia nueva, cuando se guarda, entonces recibe un código correlativo automático (`HU-001`, `HU-002`, …) que no se repite.
- [ ] Dado el formulario, cuando intenta guardar sin título, sin "Como", sin "Quiero", sin "Para" o sin criterios, entonces ve qué campo falta y no se guarda.
- [ ] Dado el formulario, cuando agrega criterios, entonces puede agregar varios, reordenarlos y quitar cualquiera antes de guardar.
- [ ] Dado el título, cuando supera 120 caracteres, entonces ve "Máximo 120 caracteres".
- [ ] Dado un criterio, cuando supera 500 caracteres, entonces ve "Máximo 500 caracteres".

### API
- [ ] `POST /api/stories` válido responde **201** con la historia creada (incluye `code`).
- [ ] Body inválido responde **400** indicando los campos con error.
