# HU-007: Aprobar o descartar casos generados
**Épica:** E4 Curación de casos · **Prioridad:** alta · **Estimación:** 3 pts

**Como** QA
**Quiero** aprobar o descartar cada caso generado
**Para** quedarme solo con los casos que valen la pena

## Criterios de aceptación
- [ ] Dado un caso Pendiente, cuando hace clic en "Aprobar", entonces pasa a **Aprobado**.
- [ ] Dado un caso Pendiente, cuando hace clic en "Descartar", entonces pasa a **Descartado** y deja de mostrarse en la lista principal.
- [ ] Dado un caso Aprobado o Descartado, cuando hace clic en "Volver a pendiente", entonces vuelve a **Pendiente**.
- [ ] Dado el detalle de una historia, cuando ve sus casos, entonces ve un contador por estado (Pendientes / Aprobados / Descartados) y puede filtrar por estado.
- [ ] Dada una lista con varios casos Pendientes, cuando hace clic en "Aprobar todos", entonces, tras confirmar, todos los Pendientes pasan a Aprobado.

### API
- [ ] `PATCH /api/cases/:id` con `{ "status": "approved" | "discarded" | "pending" }` responde **200**; estado inválido **400**; caso inexistente **404**.
