# HU-005: Editar una historia de usuario
**Épica:** E2 Historias de usuario · **Prioridad:** media · **Estimación:** 2 pts

**Como** QA
**Quiero** editar una historia ya cargada
**Para** corregirla cuando el PO aclara o cambia algo

## Criterios de aceptación
- [ ] Dado el detalle de una historia, cuando hace clic en "Editar", entonces ve el formulario con los datos actuales.
- [ ] Dado el formulario de edición, cuando cambia campos válidos y guarda, entonces ve el detalle actualizado.
- [ ] Dado el formulario de edición, cuando deja un campo obligatorio vacío, entonces aplican las mismas validaciones que al crear (HU-003).
- [ ] Dado el formulario de edición, cuando cancela, entonces no se guarda ningún cambio.
- [ ] Dada una historia editada, cuando se guarda, entonces el código no cambia.
- [ ] Dada una historia con casos generados, cuando se edita, entonces ve un aviso: "La historia cambió; revisá si los casos siguen vigentes".

### API
- [ ] `PUT /api/stories/:id` válido responde **200**; inválido **400**; inexistente **404**.

## Diseño relacionado
- `docs/arquitectura/api.md` (endpoints de historias)

## Notas
- **Supuesto:** editar la historia no borra ni regenera casos automáticamente; solo avisa.
- **Stretch del sprint 1:** si no alcanza, pasa al sprint 2.
